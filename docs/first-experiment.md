# 第一版实验：从滑动经验推断环境属性

## 基本设计

检验滑动反馈能否改善后续物理判断，以及 NODE 更新是否比离散更新更有效。

- **数据**：解析生成，每个环境独立采样摩擦系数 μ 和恢复系数 e。输入为任务类型、初速度和距离/速度阈值，共 5 维，不提供真实 μ、e。
- **学习与测试**：观察 8 次滑动事件及二元反馈，在观察 0/1/2/4/8 次后预测独立测试事件。测试答案只用于评分。
- **模型**：GRU、NODE（RK4）和多步 Euler；编码器与预测器结构一致，各自训练。NODE 和 Euler 每次更新均计算 4 次向量场。
- **对照**：高信息/低信息证据，以及正确反馈/冻结状态/打乱反馈；另设知道生成规律的物理参考方法。
- **规模与指标**：每模型 5 个训练种子、3000 步；同一测试集含 2048 个环境，每环境每类任务 24 道题。主指标为 Brier score，越低越好。

| 测试任务 | 判断内容 | 作用 |
| --- | --- | --- |
| 滑动 | 物体能否越过目标线 | 检查同类事件上的学习 |
| 碰撞后滑行 | 被撞物体能否越过目标线 | 检查依赖 μ、e 的相关迁移 |
| 瞬时反弹 | 反弹速度是否超过阈值 | 只依赖 e，作为滑动经验不应改善的对照 |

## 运行方式

完整配置见 [`configs/first_version.toml`](../configs/first_version.toml)。在仓库根目录运行：

```bash
uv run python -m intuitive_physics.experiment --config configs/first_version.toml --output outputs/first_version_repeat/runs/all
uv run python -m intuitive_physics.summarize outputs/first_version_repeat/runs/all --output outputs/first_version_repeat/summary
```

配置优先级：内置默认值 → TOML → 显式命令行参数。加 `--models gru` 可只运行 GRU，加 `--dry-run` 可只查看生效参数。输出目录须为新目录；汇总多个目录时，测试集须一致，模型与种子不得重复。

## 关键结果

2026-11-09 完成。下表为高信息条件下，8 次观察后的平均 Brier 改善量（观察前减观察后，正数表示改善）：

| 模型 | 滑动 | 碰撞后滑行 | 瞬时反弹 |
| --- | ---: | ---: | ---: |
| GRU | 0.10663 | 0.07567 | -0.00200 |
| NODE | 0.09710 | 0.07315 | -0.00251 |
| Euler | 0.09747 | 0.07321 | -0.00288 |

- 三种模型均从高信息反馈中受益，滑动和碰撞后滑行优于冻结、打乱反馈；低信息条件没有相应收益。
- NODE 与 Euler 的最终 Brier 差异在三项任务上的 95% 配对重采样区间均包含零，本轮没有 NODE 优势证据。区间按训练种子和共享事件模板组重采样，属于探索性估计。
- 反弹任务有小幅恶化。Euler 种子 4 的改善量为 -0.00567，超过预设 ±0.005 容差；增加积分子步未解决，已停止追加实验，原因尚未确定。

本地结果位于 `outputs/first_version/summary/`，负结果诊断位于 `outputs/first_version/runs/euler/seed4_diagnostic.json`；原始产物不随仓库提交。当前配置使用的测试集 31 已被查看，复跑不构成新的独立确认。

## 当前结论

第一版验证了受控环境中的属性推断和相关迁移，也跑通了实验流程；尚未证明连续更新的优势或人类直觉物理的学习机制。这里的未知参数也可以用解析方法推断，不能仅凭神经网络预测改善就声称解释了“直觉”。

下一步先明确具体学习现象和行为证据，再选择数据与任务；数据准备计划与训练分开，保存有版本的数据集供各模型共用，尚未实施。
